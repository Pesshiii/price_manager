# ADR-0016: Удаление цен отсутствующих товаров гейтится флагом `FeedMapping.is_full_inventory`

**Статус:** Принято (симметрично ADR-0014)

## Контекст

До этого изменения `apply_raw_prices` обновляла цены только для товаров, присутствующих
в фиде, и никогда не трогала `ProductPrice` товаров, которых в фиде нет. Это означало,
что при `is_full_inventory=True` (поставщик прислал полный ассортимент) устаревшие цены
товаров, которых поставщик больше не несёт, накапливались в БД бесконечно. Логика
остатков (ADR-0014) уже решила аналогичную проблему для `Stock`: при полной выгрузке
отсутствующим товарам ставится `quantity=0`. Для цен симметричного механизма не было.

## Решение

В конце `apply_raw_prices` (после обновления цен присутствующих товаров), при
`feed.feed_mapping.is_full_inventory=True`, удалять все `ProductPrice` для товаров
поставщика, отсутствующих в фиде:

```python
ProductPrice.objects.filter(supplier=supplier).exclude(
    product_id__in=present_product_ids
).delete()
```

Удаляются **все** `ProductPrice` по `(product, supplier)` — и сырые (`rule=None`),
и производные (`rule!=None`). Производные цены пересчитываются `apply_rules` после
каждого фида; без сырой цены-источника они всё равно не будут пересозданы.

Дополнительный гейт: операция не выполняется, если в фиде нет ни одной колонки с
ролью `price` (ранний `return 0` в начале функции). Фид без price-колонок не несёт
никаких утверждений о ценах, поэтому удаление было бы чистой деструкцией.

## Отличие от логики остатков

Для остатков выбрано **обнуление** (`quantity=0`), потому что ноль — осмысленное
бизнес-значение («нет в наличии»). Для цен ноль лишён смысла: `value=0` означало бы
«бесплатный товар». Поэтому для цен выбрано **удаление записи** — отсутствие
`ProductPrice` корректно читается как «у поставщика нет цены на этот товар».

## Следствия

- Деструктивная операция opt-in: при `is_full_inventory=False` (по умолчанию) поведение
  не меняется — устаревшие цены остаются до следующего явного обновления.
- Поставщики, реально присылающие полный ассортимент, должны иметь
  `FeedMapping.is_full_inventory=True`, иначе устаревшие цены не будут очищаться.
- API возвращает `null` (не `0`) для цены товара без `ProductPrice` — это корректно
  отражает отсутствие данных.
