# TransformRule formula хранится как структурированный JSON, не DSL/eval

Правила трансформации выгрузки (`TransformRule`) описывают формулы вычисления полей снимка. Мы выбрали структурированный JSON (интерпретируемый сервером) вместо строкового DSL или `eval()`.

## Рассмотренные варианты

- **Строковый DSL / `eval()`** — пользователь пишет `price * 0.85` или `map(status, {"В наличии": true})`. Читаемо, но требует парсера, создаёт риски выполнения произвольного кода в контексте воркера.
- **Структурированный JSON** — формула хранится как вложенная структура: `{"type": "arithmetic", "op": "*", "left": {"type": "field", "source": "feed", "key": "price"}, "right": 0.85}`. Вычисляется интерпретатором без `eval`. Безопасно, предсказуемо, легко валидируется схемой.

## Решение

Структурированный JSON. Паттерн уже используется в проекте (`Dataframe.instructions`) и доказал свою пригодность. Безопасность важнее читаемости: формулы создаются через UI-конструктор, а не вручную в текстовом поле, поэтому "нечитаемость" JSON не является проблемой для конечного пользователя.
