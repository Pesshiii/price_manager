# Articles app replaces blogapp

`blogapp` реализует статьи через Django-шаблоны и является legacy-приложением без DRF-слоя. Вместо расширения `blogapp` DRF API принято решение создать новое приложение `articles` с чистой моделью и REST-эндпоинтами, ориентированными на SPA-фронтенд.

## Considered Options

- **Расширить `blogapp`** — добавить serializers + DRF viewset, переиспользовав существующую модель и миграции. Отклонено: `blogapp` позиционируется как legacy, его шаблонные views не нужны SPA, а смешивание двух подходов (template + API) в одном приложении усложняет поддержку.
- **Новое приложение `articles`** — принято. Чистый старт: только модель + DRF API, без template-views и django-forms.

## Consequences

`blogapp` остаётся в кодовой базе, но более не развивается. Его шаблонные URLs могут быть отключены после переноса данных (если таковые есть).
